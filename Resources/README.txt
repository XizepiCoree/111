Свои фоны для интерфейса (необязательно)
=========================================

Положите сюда PNG-файлы, и плагин возьмёт их вместо нарисованных по умолчанию.

Один фон на все стили:

  background.png

Или отдельный фон на каждый стиль (Character). Фон меняется плавно (около 3 секунд),
когда вы выбираете стиль в плагине:

  scene1.png   Custom
  scene2.png   Sky Punch
  scene3.png   Hard Stomp
  scene4.png   Rawstyle
  scene5.png   Rumble Wall
  scene6.png   Pitch Bender
  scene7.png   Crushed 96
  scene8.png   Rusty Cannon
  scene9.png   Short Click

Порядок выбора: sceneN.png, если его нет, то background.png, если и его нет, то нарисованный фон.
Можно положить только часть файлов.

Размер: лучше 1000 x 700 пикселей (или то же соотношение сторон 10:7).
Другие пропорции не растягиваются, а обрезаются по краям.
Нижняя часть окна (примерно с 424 пикселя сверху, это около 40% высоты) закрыта диалоговым окном,
поэтому важное на картинке размещайте в верхних 60%.

Клик по фону показывает реплики героинь, поэтому фон лучше оставлять без интерактивных элементов.

Имена файлов строго такие, маленькими буквами, формат только PNG.
Используйте только те картинки, на которые у вас есть права.
После добавления файлов загрузите папку Resources на GitHub и дождитесь новой сборки.

Фоны секретного режима (по тем же правилам, размер 1000 x 700):

  secret1.png ... secret9.png   по одному на стиль Character (как scene1 ... scene9)
  secret.png                    один фон на все стили

Порядок выбора: secretN.png, если его нет, то secret.png, если и его нет, то тёмный красный нарисованный фон.
